# 对外服务接口说明

`serve.py` 启动后，采集调度、增量富化和 HTTP API 在同一个常驻进程里运行，默认监听 `http://0.0.0.0:8000`。

可通过环境变量 `API_HOST`、`API_PORT` 修改监听地址和端口。

## 接口

### GET /health

健康检查和数据量。

```json
{"status": "ok", "raw": 2693, "structured": 295, "enriched": 295}
```

### GET /intel

情报列表，支持筛选和分页。

查询参数：

| 参数 | 说明 |
| --- | --- |
| `source` | 来源，例如 `nvd`、`ghsa`、`cisa_kev` |
| `ai_relevant` | `true` 只返回 A-E 类，`false` 只返回 F 类 |
| `tag` | 按标签筛选，例如 `A`、`F`、`ollama` |
| `limit` | 每页条数，默认 100，最大 1000 |
| `offset` | 偏移量 |

返回：

```json
{"total": 295, "offset": 0, "limit": 100, "items": [...]}
```

### GET /intel/{intel_id}

单条情报详情，按 `intel_id`（如 CVE 编号）查询，未找到返回 404。

### GET /stats

数据统计：

```json
{
  "total": 295,
  "ai_relevant": 185,
  "sources": {"nvd": 38, "ghsa": 115, "...": 0},
  "categories": {"A": 125, "B": 36, "...": 0},
  "coverage": {"cvss": 0, "poc": 0, "assets": 0, "papers": 0, "attack": 0, "remediation": 0}
}
```

### POST /webhook/intel

接收外部推送的情报，请求体为 `IntelItem` 结构，系统会自动去重、打标并入库。
