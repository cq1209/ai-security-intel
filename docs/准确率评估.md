# 过滤与标签准确率评估

## 评估集

构建了一个 47 条的带标签评估集，覆盖：

- AI 安全情报（A-E）：基础设施、模型/数据、Agent/应用、供应链、政策标准
- 通用安全情报（F）：路由器、Windows、Adobe 等非 AI 漏洞
- 应排除内容：教程、评测、招聘、财经、娱乐

评估集位于 `app/cleaners/eval_cases.py`，评估脚本位于 `scripts/evaluate_accuracy.py`。

## 结果

| 指标 | 准确率 |
| --- | --- |
| 过滤准确率（是否 AI 安全情报） | 47/47 = 100% |
| 标签分类准确率（A-F 一级分类） | 40/40 = 100% |

## 运行方式

```powershell
.\.venv\Scripts\python.exe scripts\evaluate_accuracy.py
```

对应的回归测试 `tests/test_accuracy.py` 会把准确率下限固定在 95%，低于 95% 时测试会失败。
